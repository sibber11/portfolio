About

About me

I'm Sibber Ahmad, a backend developer specialising in Laravel and Vue.js. I work mostly on the server side of web applications — API design, database modelling, queues, caching and third-party integrations — with Vue.js on the front end when a project needs it.

My work spans commerce, delivery, ride-sharing, ERP accounting and ticketing products. I focus on efficient and scalable applications: clean modular Laravel code, real-time features over WebSockets, and release processes that let clients update their software without drama.
